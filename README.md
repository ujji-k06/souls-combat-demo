# Souls Combat Demo

A minimal Rojo project for experimenting with a Souls-like combat system in Roblox.

## Run

Install Rojo, then start the sync server from this directory:

```bash
rojo serve default.project.json
```

Connect the Rojo plugin in Roblox Studio to the displayed server address. The
project currently manages script services only; the existing Workspace
baseplate remains in Studio.

## Test

There are no gameplay tests yet.
